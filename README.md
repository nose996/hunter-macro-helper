# 兽王猎宏命令助手

《魔兽世界：无限》兽王猎 1–60 练级常用宏模板小工具，单文件静态页面，无后端、无外部依赖。

## 功能

- 宠物控制 / 输出循环 / 生存脱战 / 爆发增益 四类共 14 条练级宏；
- 可切换作用对象（当前目标 / 焦点）；
- 每条宏附用途说明，一键复制到游戏宏面板；
- 附「宏怎么放进游戏」操作步骤。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建、无需联网。

## 部署到 GitHub Pages

1. 新建仓库（例如 `hunter-macro-helper`），把本目录文件推到 `main` 分支；
2. 仓库 **Settings → Pages**，Source 选 `main` 分支、根目录 `/`；
3. 访问 `https://<用户名>.github.io/<仓库名>/`。

宏命令为经典旧世通用写法；技能中文名、绷带名以游戏内实测为准，标注待核的条目上线后请回客户端核对。
