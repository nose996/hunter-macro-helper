# 兽王猎练级助手

《魔兽世界：无限》兽王猎 1–60 练级小工具，单文件静态页面，无后端、无外部依赖。页面分「宏命令」「练级指南」两个视图。

## 功能

- **宏命令视图**：宠物控制 / 输出循环 / 生存脱战 / 爆发增益 四类共 15 条，只收动作条做不到的一键组合、技能序列、修饰键分支、指向目标和宠物指令；
- 指向类宏按 鼠标指向 > 当前目标 > 焦点 自动选目标；每条宏附用途说明，一键复制到游戏宏面板；分类分组可折叠、默认展开，可一键全部展开/收起；
- **练级指南视图**：1–60 级路线图（地图 / 技能 / 天赋 / 宠物 / 手法分段）、技能全表、宠物选择与训练、种族与专业；
- 右下角悬浮按钮 + 页脚反馈入口，弹窗选择涉及宏并填写问题，提交到仓库 Issues；
- 附「宏怎么放进游戏」操作步骤。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建、无需联网。

## 部署到 GitHub Pages

仓库自带 `.github/workflows/deploy-pages.yml`：推送到 `main` 分支后，GitHub Actions 自动构建并发布；仓库 **Settings → Pages** 的 Source 保持 GitHub Actions。线上地址 `https://<用户名>.github.io/<仓库名>/`。

## 口径与免责

宏命令为经典旧世通用写法；练级路线、技能、宠物与种族专业内容整理自公开英文练级指南并对照中文数据库核对译名。技能中文名、解锁等级与掉落以游戏内实测为准，标注「待核」的条目上线后请回客户端核对。

本项目为玩家自制非官方工具，与暴雪娱乐 / 网易无关。游戏名称、角色与素材版权归各自所有者。
